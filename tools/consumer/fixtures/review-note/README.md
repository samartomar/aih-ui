# Independent note example

The note, license and recipes are real locally authored material. `note-fixture.mjs`
binds their exact repository paths to immutable source commit
`4878543b94c81fbc836ca136150c22c9a9615bfb` in `samartomar/aih-ui`.
Qualification compares supplied bytes with that commit's Git blobs.

The retained `declaration.json` is an illustrative declaration template. The
loader replaces its illustrative repository/path fields with the actual source
snapshot and produces a separately hashed local declaration. `next-note.md`
and `additional-recipe.json` are committed authored update/expansion examples.
They do not claim upstream framework or native-client support. Generic UI and
Core source is unchanged when the additional declaration is supplied.

Git/npm/organization intake tests exercise portable source records and required
bytes. Their transport envelopes are labelled fixtures; they do not claim network
acquisition, npm extraction or organization authentication.
