# Triage labels

Use the five default canonical roles. The canonical labels are installed; verify the live tracker before changes.

| Skill role | Tracker label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Use at most one canonical triage state on an issue. Classification and version-impact labels do not imply readiness. Recheck live labels before mutation. A missing mapping blocks that label edit, not work on an agreed issue.
